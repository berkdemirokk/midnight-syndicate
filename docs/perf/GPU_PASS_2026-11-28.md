# Mobile GPU pass, 2026-11-28 (dev PC numbers only)

Branch `wp/perf`, base `release/rc-2026-11-28` (eeee5da). Desktop RTX 5060 Ti, Vulkan, Mobile renderer, 1920x1061 viewport.
These are not phone numbers. Phone frame times need the device card (ROADMAP step 4).

## What changed

| Item | Change | Files |
|---|---|---|
| Mirror viewport diet | Mirror env: glow off, linear tonemap, exposure 1.0 (main pass still tonemaps once). Mirror viewport: positional shadow atlas 0, MSAA off. | `game/fx/planar_reflection.gd` |
| Reflection probes honoured | Track load skips `_build_probes` when `reflection_probes_enabled` is false (Low). | `game/world/city_01/city_builder.gd` (one `if`) |
| Dead preset field removed | `max_dynamic_lights` was read nowhere; deleted (not wired to the light split). | `game/core/graphics_preset.gd` |
| Soft shadow per preset | New `shadow_filter`: High SOFT_LOW, Medium SOFT_VERY_LOW (default), Low HARD. Set in `_apply_renderer` via `RenderingServer.directional_soft_shadow_filter_set_quality`. | `graphics_preset.gd`, `settings.gd` |
| Post AA per preset | New `screen_space_aa`: Medium FXAA, Low and High disabled. Applied in `apply_to_viewport`. High MSAA stays 2X. | `graphics_preset.gd`, `settings.gd` |
| Tests | 4 new tests (preset values, viewport AA, mirror viewport, mirror environment). Full suite 359 tests, 0 failed. | `game/tests/test_perf_presets.gd` |

Not changed, by instruction: phone render scale gate (`scaling_confirmed_on_device` stays false), High MSAA, `time_of_day.gd`, shaders.

Draws and primitives are repeatable. Frame times are not: the same baseline `pack_medium` shot read 5.66 ms in one run and 3.42 ms in another, so frame-time differences below about 2 ms are noise.

Read-outs:
- Draw calls are unchanged everywhere. The sign cut from the mirror was not done (see below), so no draw saving is expected.
- Low: the probe skip and HARD shadows are the only Low changes. The Low shots are faster, but a single run is not enough to call it a gain.
- Medium: FXAA adds one full-screen pass. The average rose in this run, but noise is larger than that difference. Not conclusive.
- High night: the mirror changes did not raise the primitive count beyond +3.8k (about 1%). The night hero average fell, which is probably noise. Not claimed as a gain.

- FXAA on Medium is a guess until a phone or a clean A/B shows its cost.
- Only desktop numbers. A12-class phone costs are unknown.
