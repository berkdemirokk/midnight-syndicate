# Routes package, 2026-11-28 (partial)

Status: the reverse-direction engine is in and tested. The career restructure, point-to-point sprints, shortcut
variants, event select data, i18n keys and the captures are NOT done (see "Not done").

## Done

- `game/world/track.gd`: `Track.set_reversed(on)` runs a track the other way on the existing geometry. The racing
  line is flipped (sample j takes old sample count - j, tangents and curvature change sign, speed profile rebuilt).
  Each grid slot moves to the mirror of its progress about progress 0 (same lateral position on the road) and faces
  the reversed tangent. Idempotent; `is_reversed()` reports the state. Call it after the Track is in the tree.
- `game/race/race_config.gd`: `reverse_route` export (default false).
- `game/race/events.gd`: `config_for` copies an event's `"reverse": true` into `reverse_route`. No event sets it yet.
- `game/tests/test_routes.gd` (3 tests on world/istanbul_bogaz):
  - reversed line equals the authored line at len - s (max error 0.0 m on 60 m samples), curvature sign flips,
    round trip restores the line;
  - authored grid faces the line; each reversed slot keeps its numeric progress (max progress error 0.02 m, wrap-aware)
    and sits on the authored mirror point at its lateral distance from the road centre (max position error 0.0 m);
    reversed slots face the reversed tangent. The first version of this check compared against len - s and was
    vacuous (its guard turned every mismatch into 0); it was replaced in the review fix;
  - 3 AI cars finish one reversed lap through RaceManager (dev PC, headless: 48.2 s race time, all classified).
- Full headless suite: 470 tests, 0 failed.

## Lead review additions (2026-11-28)

- Hook wired: `game/race/race_scene.gd` calls `track.set_reversed(config_used.reverse_route)` right after
  `_world.add_child(track)`, before the cars are placed and before traffic, pursuit and dressing read the track.
  No event sets `"reverse"` yet, so the career plays exactly as before.
- Mirrored slot height: a slot now keeps its height above the line at the mirror point (it copied the authored
  absolute height before, which would float or bury cars on a track with elevation). Bogaz is flat at its grid
  (elevation delta 0.0 m), so Bogaz results did not change.
- New test `test_reverse_grid_on_every_track`: City 01, Bogaz and Maslak reversed grids face the new direction (all

  No reversed AI lap is run on City 01 or Maslak yet.

  results). Grid shot looked at: six cars on the road in the Ortakoy shop street, staggered, facing the run

  Gap: the reversed grid has no painted slot boxes or start line (the decals belong to the environment package).

## Measured facts that shaped the design

- Istanbul Bogaz lap length 2205.4 m. Measured: the authored start grid sits at progress 193.9 to 249.8 m (first and
  last slot printed by the test). race_manager.gd turns progress above half a lap into negative distance and
  below it into positive distance, so these slots count as 194 to 250 m ahead of the line, not behind it. The
  comment in race_manager ("grid slots are negative") does not match the authored Bogaz grid. The reversed grid
  copies the same numeric placement, so it has the same property. Whether this is a real start-order or lap-count
  defect is UNVERIFIED: it needs a start-grid capture of the authored and reversed grids (not done, no GPU run here)
  and a decision by the lead. Geometry of the reversed grid is verified numerically only, not by a capture.
- The first draft rotated the authored facing by 180 degrees, which faced the wrong way on this loop because the
  tangent at the mirror point differs from the one at the authored slot. Facing now comes from the tangent at the
  mirror point.
